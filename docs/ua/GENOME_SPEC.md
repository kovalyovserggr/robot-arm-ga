# RobotArmGA — специфікація генома v1.0

Дата: 2026-07-08. Базується на рішеннях Р3–Р6 (див. DECISIONS.md).
Геном: 42 речові гени, кожен зберігається нормованим g ∈ [-1, 1].
Розгортання у фізичний параметр — лінійне:

    p = p_min + (g + 1)/2 · (p_max − p_min)                    (1)

Усі оператори GA (кросовер, гаусова мутація σ, кліпінг) працюють
у нормованому просторі — один масштаб для всіх генів.

## 1. Конструктивні гени (18): DH-параметри

Модифікована конвенція Денавіта–Хартенберга. Ланка i (i = 1..6)
описується трійкою (a_i, α_i, d_i); змінна суглоба — θ_i (револьютний,
вісь z_i). Ланцюжок в Unity: Transform-зсув по x на a_i → поворот
навколо x на α_i → зсув по z на d_i → ArticulationBody з обертанням
навколо z.

| Індекс | Ген | Фізичний зміст | p_min | p_max | Од. |
|---|---|---|---|---|---|
| 0–5   | a_1..a_6 | довжина ланки (спільний перпендикуляр осей) | 0 | 0.35 | м |
| 6–11  | α_1..α_6 | кут скручування сусідніх осей | −90 | +90 | ° |
| 12–17 | d_1..d_6 | зміщення вздовж осі суглоба | 0 | 0.30 | м |

Примітки:
- a_i = 0 дозволено свідомо: нульові ланки дають GA змогу "відкрити"
  сферичне зап'ястя (стандарт промислових 6R, де a_4 = a_5 = 0).
- Діапазон α обмежено половиною кола: α і α ± 180° у комбінації зі
  знаком θ дають дзеркальні дублікати конфігурацій (надлишковість
  кодування, шкідлива для кросовера).
- Максимальний виліт руки Σ(a_i + d_i) = 3.9 м — простір пошуку
  свідомо ширший за робочу зону; нежиттєздатні "коротуни" відсікаються
  обмеженням успішності (Р6), частину стартової популяції засіваємо
  конфігураціями з гарантованим досяганням (див. §4).

## 2. Гени руху (24): ключові кути по фазах

Фази монтажу j = 1..4: (1) підхід і захоплення деталі → (2) перенесення
→ (3) позиціонування над точкою монтажу → (4) встановлення.
Ген θ̂_ij задає цільовий кут суглоба i в кінці фази j.

| Індекс | Ген | Фізичний зміст | p_min | p_max | Од. |
|---|---|---|---|---|---|
| 18–23 | θ̂_1j..θ̂_6j, j=1 | цільова поза, кінець фази 1 | −150 | +150 | ° |
| 24–29 | j=2 | цільова поза, кінець фази 2 | −150 | +150 | ° |
| 30–35 | j=3 | цільова поза, кінець фази 3 | −150 | +150 | ° |
| 36–41 | j=4 | цільова поза, кінець фази 4 | −150 | +150 | ° |

- Ліміти ±150° — типові для промислових револьютних суглобів; фіксовані
  (не еволюціонують) у v1.0.
- Стартова поза θ_i(0) = 0 ∀i — однакова для всіх особин (чесний старт).
- Відпрацювання: цільові кути подаються у drive ArticulationBody
  (stiffness/damping фіксовані константами середовища); перехід між
  ключовими кадрами — лінійна інтерполяція цілі всередині фази
  (фізика сама згладжує через інерцію і драйв).
- Тривалості фаз v1.0 фіксовані: t = (2.0, 2.5, 2.5, 2.0) с, цикл 9 с.
  Розширення +4 гени тривалостей (t_j ∈ [0.5, 4.0] с) — окремий
  експеримент (Р5), індекси 42–45, у v1.0 не використовуються.

## 4. Ініціалізація популяції

- 90% особин: усі гени ~ U(−1, 1).
- 10% особин: "засів" — конструкція з рівномірними ланками
  (a_i = 0.2 м, α чергування 0/90°, d_i = 0.05 м) + мутаційний шум
  σ = 0.15; рухи випадкові. Гарантує наявність рук, що фізично
  дістають до деталі й точки монтажу, з першого покоління.
- IK-засів поз (опція, Р5): для засіяних конструкцій кути фаз 1 і 3
  обчислюються CCD-солвером до цілей "деталь"/"точка монтажу".

## 5. Вимірювання критеріїв (клієнт → IndividualResult)

| Поле | Формула вимірювання |
|---|---|
| assembly_time (T) | час від t=0 до success; якщо fail → ліміт 30 с |
| energy (E) | E = Σ_кроків Σ_i \|τ_i · Δθ_i\|, τ з jointForce |
| W_i (на суглоб) | накопичена \|τ_i·Δθ_i\| по кроках — вектор 6 значень |
| wear_cv (W_cv) | std(W_1..W_6) / mean(W_1..W_6) |
| wear_max (W_max) | max(W_1..W_6) |
| precision_error | відстань деталь↔точка монтажу в момент встановлення (або мінімальна досягнута, якщо fail) |
| collisions | кількість контактів ланок із забороненими об'єктами і самоперетинів |
| success | встановлено в межах ε_pos до ліміту часу |

Розширення протоколу: IndividualResult доповнюється полями
wear_cv, wear_max, joint_work[6] (масив). Fitness-згортка (етап 1)
рахується на сервері з сирих метрик — ваги в одному місці.

## 6. Контрольні цифри

- Розмір генома: 42 (v1.0) / 46 (з тривалостями фаз).
- Популяція: 100 (Р8). Мутація: p = 2/42 ≈ 0.05 на ген, σ = 0.15.
- JSON одного покоління: 100 × 42 float ≈ 60 КБ — транспорт без змін.
- Config для клієнта: construction_gene_count = 18, motion_gene_count = 24,
  population_size = 100 (задається в Unity Inspector, код не змінюється).
