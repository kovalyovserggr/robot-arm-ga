# RobotArmGA — журнал результатів експериментів
Оновлено: 2026-07-09. Прив'язка до файлів графіків Сергія (результат_N.png).
Кожен запис: конфігурація → спостереження → інтерпретація → теза для статті.

## Як читати графіки (легенда для всіх записів)
- Fitness best/mean: best ≈ 0..-1 означає наявність успішних особин
  (успіх → F = -eff); best ≈ -5..-8 — успішних немає.
- Успішні монтажі, %: частка особин покоління з монтажем у поточному допуску.
- Похибка (log): min — найкраща особина; зелений пунктир — допуск curriculum
  (з серії B); червоний — цільові 5 мм.
- Надійність: W_cv (рівномірність зносу, менше=краще), W_max (піковий знос).

## Запис R1. Перші наскрізні прогони (результат ~1-4, 07-08.07)
Конфіг: population 20-300, розкладний curriculum ще відсутній.
Спостереження: плато похибки ~0.75-0.8 м; success 0% (60 000+ оцінок).
Інтерпретація: два дефекти — (а) "ледарі" (енергія душила точність) →
ієрархічна згортка; (б) ворота захвату 10 мм + похибка за фінальною
позою → нема градієнта до воріт.
Теза: fitness shaping ітерації №1-2; сирі метрики завжди в протоколі —
діагнози ставились ретроспективно за графіками.

## Запис R2. Серія A: розкладний curriculum (результат_5, 6, 7; 3 сіди)
Конфіг: 200 пок. × 300, допуск 50·0.98^g мм, радіус захвату = 2×допуск,
градієнт по найкращому підходу, P-контролер σ.
Спостереження (відтворено на 3/3 сідах):
- ПЕРШІ УСПІХИ в історії проекту: 3-5% на поколіннях ~20-75;
- min-похибка пробиває 5 мм (№5: 1.2 мм на пок. ~50);
- КОЛАПС на пок. 75-90: успіхи -> 0 назавжди; зубці best fitness
  (-0.4 ↔ -8) = та сама еліта перестає проходити допуск, що стискається.
Інтерпретація: розкладний (розімкнений) curriculum відривається від
реального темпу навчання; навичка на 2-5% носіїв не консолідується
(кросовер успішний×невдаха руйнує).
Теза: пряме експериментальне свідчення проти open-loop розкладу складності;
6 прогонів (A vs B) = ядро підрозділу порівняння curriculum-стратегій.

## Запис R3. Серія B: self-paced curriculum, тригер Шмітта
(результат_9, 10, 11; 3 сіди)
Конфіг: як A, але допуск керується успішністю: стискання ×0.96 при
успіху ≥25%, відпускання при <2% (гістерезис), стеля 80 мм.
Спостереження (відтворено на 3/3):
- успіхи ЖИВІ всі 200 пок.: стабільно 10-35%, без колапсу;
- зелена крива допуску: старт 50 мм → відпускання до 80 мм (перші ~20 пок.,
  успіх 0% — гістерезис РЯТУЄ старт) → спуск услід за популяцією →
  рівновага ~20-28 мм;
- min-похибка: 5-10 мм постійно, епізодично <5 мм (№11: до ~1.5 мм);
- ЕПОХА ЕФЕКТИВНОСТІ: W_cv mean 0.50 → 0.15-0.18, W_max best → сотні Дж —
  критерії надійності вперше реально оптимізуються (ієрархічні ворота
  відчинились завдяки масовості успіху).
Теза: замкнений контур складності стабілізує еволюцію навички;
побічний ефект — увімкнення оптимізації надійності. ГОЛОВНИЙ результат
для теми дисертації (ефективність І надійність).

## Запис R4. "Чи не погіршення?" (питання Сергія — методологічно важливе)
Спостереження-привід: серія A торкалась 1-5 мм, серія B рівноважиться
на 20-28 мм → враження регресу.
Розбір:
- A: 1-5 мм — ЕПІЗОДИЧНИЙ рекорд одиничної еліти на вузькому вікні
  поколінь, після якого лінія вимерла (не відтворюється, не утримується);
- B: 20-28 мм — УТРИМУВАНА здатність популяції (10-35% успішних, кожне
  покоління, до кінця прогону), при цьому min так само пірнає під 5 мм;
- 20-28 мм — не стеля системи, а РІВНОВАГА ПРИ УСТАВЦІ 25%: рівноважний
  допуск є функцією уставки регулятора (нижча уставка → глибша рівновага
  → більша крихкість).
Теза для статті: коректна метрика прогресу — не разовий мінімум похибки,
а рівноважний допуск утримуваної успішності (sustained tolerance);
пара (уставка → рівноважний допуск) = вимірювана характеристика системи.

## Запис R5. Відкриті ручки для поглиблення рівноваги (черга експериментів)
1) Уставка-відпал: почати з 25% (консолідація) → після стабілізації
   знизити до 5-10% (поглиблення) — "мета-curriculum" на уставці;
2) Серія Т10: уставка ∈ {4%, 25%, 50%} × 3 сіди → крива
   "рівноважний допуск vs уставка" (головний рисунок підрозділу);
3) Поетапна оцінка по фазах (Т8) — щільніший градієнт;
4) Самоадаптивна σ (Т4) — тонше доведення біля рівноваги;
5) Довші прогони (500 пок.) — перевірка, чи рівновага дрейфує вниз.

## Запис R6. Оглядини чемпіона (інструмент готовий, дані очікуються)
- Сервер зберігає champion.json (геном+метрики+допуск перемоги);
  ChampionReplay крутить його на одній площадці.
- Чек-лист оглядин: (а) відтворюваність success по повторах (вхід у
  robustness Т7); (б) конструкція — чи "схуд" чемпіон (Т9, W_max ~200 Дж
  натякає що так); (в) траєкторія — чи збереглася емерджентна стратегія
  "захід знизу вгору" (кандидат у розділ аналізу рішень).
